# Shifu Connect

Shifu Connect is an interactive platform for entrepreneurs and dreamers looking to turn their ideas into reality. The platform offers tools for idea validation, roadmapping, resource access, and connecting with mentors, talent, and investors.

## Features

- **Smart Discovery**: Personalized resources based on your location, experience, and goals
- **Ideaboard**: Evaluate and refine your startup ideas
- **Roadmap**: Build a customized journey from idea to launch with milestone tracking
- **Resources**: Access playbooks, templates, and courses tailored to your needs
- **Connect**: Find mentors, talent, and investors to help bring your idea to life

## Tech Stack

- Next.js 14
- React
- TypeScript
- Tailwind CSS
- Framer Motion

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```
   npm install
   ```
3. Run the development server:
   ```
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Project Structure

- `/src/app`: Main application pages and layouts
- `/src/components`: Reusable UI components
- `/src/styles`: Global styling and Tailwind configuration
- `/src/data`: Mock data and schemas
- `/src/lib`: Utility functions and shared logic
